# PETs Accelerator Application -- Outlier Ventures x Midnight Foundation

## Product: NightForge Explorer -- Privacy Analytics Infrastructure for Midnight

### The Product

NightForge Explorer (nightforge.jp) is a production-grade privacy analytics platform for the Midnight blockchain network. Unlike conventional block explorers that simply list transactions and blocks, NightForge is built from the ground up around privacy metrics -- making it the first tool in the Midnight ecosystem to quantify and visualize the network's zero-knowledge privacy guarantees.

The platform is live today, serving all three Midnight networks (mainnet, preprod, preview) from a single open-source monorepo. It tracks a 99% shielded ratio through on-chain event analysis, displays ZK verified badges on shielded transactions, monitors over 36,000 cross-chain bridge operations, follows 19 deployed smart contracts and 1,200+ contract calls, provides on-chain governance tracking for council proposals and votes, and visualizes Cardano settlement layer anchoring. It includes epoch timelines, network health scoring, validator committee displays, block producer tracking, and a live block pulse animation. The entire interface is available in Japanese and English, with 114 translated elements.

### The Opportunity

Midnight is the most significant privacy-focused blockchain to launch since Zcash, but it is in its earliest infrastructure phase. The network needs developer tools, analytics platforms, and user-facing interfaces that match the sophistication of its cryptography. This is the window where foundational infrastructure gets built and where first movers define the ecosystem.

The Japanese blockchain market represents a critical gap. Japan has one of the most mature regulatory environments for digital assets, a highly active developer community, and strong institutional interest in privacy-compliant blockchain solutions. Yet there is currently zero Midnight infrastructure purpose-built for this market. NightForge is already there, with native Japanese language support and a team that understands the regulatory and cultural landscape.

### The Privacy-Enhancing Technology Angle

NightForge does not just sit on top of a privacy blockchain -- it makes privacy measurable. The shielded ratio dashboard provides the first quantitative metric for how effectively Midnight's ZK proofs are protecting user data. The ZK verified badge system makes the abstract concept of zero-knowledge proofs concrete for end users. The governance tracker ensures that the privacy-first design philosophy extends to how the network is governed. This is privacy analytics as infrastructure: giving users, developers, regulators, and institutions the tools to verify that privacy guarantees are working as intended.

### Technical Capability

The entire NightForge platform was designed, built, and deployed to production in a matter of days -- across three separate network environments, with full nginx infrastructure, systemd process management, automated restarts, and interactive API documentation. This is not a prototype or a pitch deck. It is a production system processing live blockchain data right now.

### Business Model

NightForge's accelerator trajectory targets three revenue streams. First, API services: a tiered developer API offering real-time and historical privacy analytics, contract monitoring, and governance data for dApp builders and institutional users. Second, premium analytics: advanced dashboards for compliance teams, auditors, and enterprises that need verifiable proof of privacy-preserving operations for GDPR, HIPAA, and Japanese APPI regulatory requirements. Third, enterprise infrastructure: white-label explorer and analytics deployments for organizations building on Midnight who need private, customized network visibility.
